# Data Fetching – Fetch References and Citations

## references_citations.py

Step 3 of `main_script.py`.

## Location

`data_fetching/fetch_authors.py`

## Overview
This script fetches citation and reference links for a set of article DOIs (from a journal ISSN) using the OpenCitations API, then saves two line-delimited JSON files: one for who cites each DOI, and one for what each DOI cites. It parallelizes requests with a thread pool, shows progress with `tqdm`, and normalizes returned DOIs.

It returns two JSON files:

- citations.json → with information about articles that cited the input DOIs.
- references.json → with information about articles references by the input DOIs.

## Inputs

### Required
- **ISSN** (string) — provided via **STDIN** from ``main_script.py`.
- **Articles file** – must already exist at: `data_fetching/data/<ISSN>/articles.json` (generated by `fetch_articles.py`)


## Outputs

### Files
- **Citations (JSON Lines)**: `data_fetching/data/<ISSN>/citations.json`
 Each record includes:
 - `source_doi`: "<input DOI>"
 - `related_doi`: "<DOI that cites source>"
- - **References (JSON Lines)**: `data_fetching/data/<ISSN>/references.json`
 Each record includes:
 - `source_doi`: "<input DOI>"
 - `related_doi`: "<DOI that the source references>"

 Both are saved with pretty-printed JSON (orient="records", indent=2). The script logs counts and save locations to stdout.

### Console output

You’ll see counts and two progress bars:
- “📦 Fetching citations”
- “📦 Fetching references”
On success, the script prints paths to the two output files. 

## Usage

### Parameters and configuration
- Calls `https://opencitations.net/index/api/v2/{mode}/doi:{doi}` for `mode ∈ {citations, references}` and extracts the related DOI (`citing` or ``cited).
- Cleans related_doi by stripping any `doi:` prefix via regex.
- Concurrency: up to 10 threads (`MAX_WORKERS = 10`) for faster fetching. Adjust in the script if needed.
- Timeouts & errors: Each request has a 10s timeout; network exceptions return an empty list for that DOI (the run continues). references_citations
- Normalization: If the API returns values like `doi:10.xxxx/...`, the script extracts the canonical DOI with `str.extract(r'doi:([^ ]+)')`. 
- API endpoints used:
 - Citations: `/index/api/v2/citations/doi:{doi}`
 - References: `/index/api/v2/references/doi:{doi}` 

### Dependencies
- Python libs: `requests`, `pandas`, `tqdm`.
- A shared `requests.Session()` is used.
- Concurrency via `concurrent.futures.ThreadPoolExecutor`.
