# Data Fetching – Top competitors

## fetch_authors.py

Step 4 of `main_script.py`.

## Location

`data_fetching/top_competitors_citations.py`

## Overview
This script ranks competitor journals for a given base ISSN by resolving the journals behind all related DOIs found in that ISSN’s citations and references, then scoring and listing the most frequently co‑appearing venues. It reads the ISSN from STDIN, loads citations.json and references.json, resolves each related_doi to a journal via Crossref (fallback: OpenAlex), aggregates counts, computes a total_score = citations + references, excludes the base journal itself, prints a Top 10, and writes full and top lists to disk. 

## Inputs

### Required
- **ISSN** (string) — provided via **STDIN** from `main_script.py`.
- **Citations file** – must already exist at: `data_fetching/data/<ISSN>/citations.json` (generated by `references_citations.py`).
- **References file** – must already exist at: `data_fetching/data/<ISSN>/references.json` (generated by `references_citations.py`).

## Outputs

### Files
- **Total competitors (JSON Lines)**: `data_fetching/data/<ISSN>/competitors_citations.json`
 Complete ranking with:
 - `journal` — name of competitor journal
 - `issn`– ISSN of competitor nournal
 - `citations` – number of citations from the competitor journal
 - `references`– number of references to the competitor journal
 - `total_score`– sum of citations from and references to the competitor jorurnal
- **Total competitors (JSON Lines)**: `data_fetching/data/<ISSN>/top_competitors.json`
 - Shows the top 10 subset of competitors.

### Console output
- Progress bar: `📚 Resolving DOIs to journals`.
- Header for results: `🏆 Top 10 Competitor Journals (excluding base journal):`.
- Formatted table of the top 10 competitor journals.
- Save confirmation for the complete ranking: `💾 Saved full ranked competitor journal list to data_fetching/data/{ISSN}/competitors_citations.json`.

## Usage

### Parameters and configuration
- API Crossref: `https://api.crossref.org/works/{doi}` (primary resolver)
- API OpenAlex: `https://api.openalex.org/works/https://doi.org/{doi}` (fallback). 
- Headers: `{"User-Agent": "mailto:paulafmed@gmail.com"}` (replace with your email if needed).
- Concurrency: `MAX_WORKERS = 10` (threads processing DOIs in parallel).

### Flow and data shaping
- Loads both link files and collects unique `related_doi` values to resolve.
- Resolves each DOI to (`journal`, `issn`) via Crossref → OpenAlex fallback, in parallel with a progress bar.
- Merges resolved venue data back into citations and references.
- Aggregates counts and computes the total score, then sorts descending.
- Excludes rows matching the base ISSN and prints the Top 10.
- Saves the full ranking and the top 10 to JSON files.
